# Square Art Construction Ltd

Website for Square Art Construction Ltd — residential construction in Calgary, Alberta.
Single-family homes, duplexes, townhomes, additions and renovations, foundation to finish.

**Live site:** https://squareartconstruction.com

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Home — hero, trust bar, home types, scroll-driven build animation, trades, process, testimonials |
| `services.html` | Nine trades in detail + FAQ |
| `process.html` | Five build phases and typical timelines |
| `projects.html` | Recent homes with hover previews |
| `about.html` | Story, values, service area |
| `contact.html` | Quote form (opens the visitor's email app) |
| `404.html` | Custom not-found page |
| `site.css` | All styling and design tokens |
| `site.js` | Smooth scroll, reveals, cursor, marquee, form handler |
| `CNAME` | Custom domain for GitHub Pages |
| `sitemap.xml`, `robots.txt` | Search engine indexing |
| `og.png`, `favicon.*` | Social share image and icons |

## Tech

Plain static HTML, CSS and JavaScript — no build step, no framework, no dependencies
to install. Animation uses GSAP + ScrollTrigger + Lenis loaded from a CDN. Fonts are
Clash Display and General Sans (Fontshare) plus Space Mono (Google Fonts).

Hosted on GitHub Pages. See **DEPLOY.md** for setup and DNS.
